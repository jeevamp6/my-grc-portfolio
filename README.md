# Jeeva MP - GRC Analyst Portfolio

Welcome to the Governance, Risk, and Compliance (GRC) Analyst portfolio repository of **Jeeva MP**.

## 🌐 Live Portfolio
You can host and view this portfolio using **GitHub Pages**:
1. Go to repository **Settings** -> **Pages**.
2. Under **Branch**, select `main` and `/ (root)`.
3. Click **Save**.

Your portfolio will then be live at:
`https://jeevamp6.github.io/my-grc-portfolio/`
